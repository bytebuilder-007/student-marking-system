Student Marks Manager

A beginner-friendly Java console program that stores student marks in an array and calculates the average, highest, lowest, and overall grade.

Features

- Stores marks for any number of students using a 1D array
- Validates input (marks must be between 0 and 100)
- Calculates the class average
- Finds the highest and lowest marks
- Assigns a grade based on the average

Grading Scale

| Average   | Grade |

| 90 - 100  | A     |
| 75 - 89   | B     |
| 60 - 74   | C     |
| 40 - 59   | D     |
| Below 40  | F     |

Concepts Used

- 1D arrays
- Loops ("for", "do-while")
- Methods
- Conditional statements
- User input with "Scanner"

How to Run

Make sure you have Java IDE installed, then run:

StudentMarksManager.java
StudentMarksManager

Sample Output

Enter number of students: 3
Enter marks of student 1 (0-100): 85
Enter marks of student 2 (0-100): 92
Enter marks of student 3 (0-100): 78

Result

Student 1: 85
Student 2: 92
Student 3: 78
Average : 85.00
Highest : 92
Lowest  : 78
Class grade (by average): B
